# After Rain

An interactive miniature forest after rainfall, seen from insect height on a blue moonlit night. A standalone creative coding and portfolio project, independent from Skógafoss.

## Status

Creative direction is agreed. Implementation is starting in a separate Codex task.

The first milestone is a polished, running browser scene with a strong opening composition and tactile interactions. Read [BRIEF.md](BRIEF.md) for the visual direction and scope.

## Development direction

Three.js with WebGPU and TSL where they help the scene, using a lightweight local frontend toolchain. Exact dependencies and run commands will be documented as implementation proceeds.

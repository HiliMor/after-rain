# After Rain demo media

Captured by the project owner from the running scene on September 21, 2026. These files are derived from the supplied screen recording; they are not generated scene imagery.

- `after-rain-demo.gif` — an 8-second looping excerpt, from 00:02 to 00:10 of the original recording, resized to 640 pixels wide at 8 frames per second. Embedded in the repository README as a compact animated preview.
- `after-rain-demo.mp4` — the complete approximately 19-second recording, encoded as H.264 at 1920 × 1010 and 30 frames per second, with fast-start metadata for browser playback. The original recording contains no audio.
- `after-rain-cover.jpg` — a still extracted at 00:09.8, resized to 1600 pixels wide.

The original recording remains separate from the repository. Compression and resizing are the only visual processing applied; the GIF additionally uses an excerpt and a reduced color palette.
